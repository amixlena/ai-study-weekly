02全部学习解读

  • W08
    Document Pipeline + Chunk本周
    用纯 Python 读取 TXT / Markdown，完成保守清洗与 metadata 设计，建立可重复运行的 Document Pipeline。实现固定窗口与段落优先两种 Chunk 策略，对比 chunk size / overlap，并用校验与测试留下工程证据。
  • W07
    FastAPI + RAG 全景上周
    把已有 LLM / Agent Demo 封装为 FastAPI 服务，明确请求、响应、状态码、异常与测试。完成最小 Embedding / 相似度实验并画清 RAG 全流程，用证据自查进入工程阶段前的 Gate 1。
  • W06
    Tool Calling + Agent Loop上周
    以 Hello-Agents 为主教材，学习工具定义、参数校验、结果回传与最小 Agent 循环。交付两个工具及验证脚本，覆盖正常调用、直接回答、参数错误、工具失败和步数上限。
  • W05
    Structured Output + Context + Agent 全景上周
    用 JSON Schema、Pydantic 与 Structured Output 建立可校验的程序接口。交付双版本 Demo、失败校验与 Context 对照，画清 Prompt / Workflow / Agent / RAG 边界。
  • W04
    LLM 最小底层与模型行为历史归档
    建立 Token → Embedding → Attention / Transformer → Sampling 的生成直觉。交付最小 API Demo、参数与 Token 实验，观察 Streaming / Error，并闭卷重写。
  • W03
    基础启动收尾 + 转入 LLM 主线历史重建
    把运行、修改、Debug、提交和解释串成一个 Python + Git 小闭环。交付综合练习与按需补齐清单；Type Hint、异常、uv 等在真正阻塞时再补。
  • W02
    Python 数据结构 + Git 基础工作流历史重建
    围绕 list / dict / 嵌套结构练过滤、统计、排序，并按函数组织逻辑。交付数据处理练习，用 status → diff → add → commit → log 记录完整开发变化。
  • W01
    Python 基线 + Git 初始化历史重建
    确认变量、类型、条件、循环、函数与模块达到最低可用水平。交付可运行的 Python 小练习和 Git 仓库，独立完成一次修改、检查与提交。
