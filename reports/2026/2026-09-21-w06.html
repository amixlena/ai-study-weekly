任务一：工具定义与参数校验

3 小时
P0Tool Calling L3

要解决的问题：模型怎样知道有哪些工具、每个工具何时使用，以及参数该长什么样。

对本周自定义的 Python 工具，模型输出工具请求，你的程序执行实际函数。工具描述供模型选择，参数 Schema 说明输入结构，本地校验负责发现不符合约束的请求。仅仅在 Prompt 中写“你可以查课表”，还没有完成工具接入。

  1. 先复跑 W05 的结构化输出与 Pydantic 校验示例，确认成功和失败路径都能解释。
  2. 直接在 Python 中调用两个工具，保证函数本身能正常工作。
  3. 为工具写名称、清晰描述和参数结构，将工具名对应到函数。
  4. 为天数、每天时长等参数设置合理约束，故意传入缺字段或无法转换的类型。

这项任务怎么学

资料：Hello-Agents 4.2.2；官方工具定义；Pydantic Models。

方法：AI 解释“函数 / Schema / 校验”的关系 → 官方页面核对字段 → 你先写 → 运行合法与非法参数 → AI 检查。

产出与验收：两个可直接调用的函数、对应参数模型；能指出非法输入在哪一层被识别。

建议时长：3h：复跑 W05 校验 0.5h；工具 Schema 与接口阅读 0.75h；实现两个函数和参数校验 1.25h；反例检查 0.5h。

任务二：跑通一次完整工具调用

3 小时
P0Tool Calling L3

要解决的问题：模型提出调用请求以后，怎样得到真实结果，并利用结果回答用户。

  1. 把工具定义与用户问题交给模型，检查模型返回的工具名称、参数与调用标识。
  2. 校验参数，交给对应的 Python 函数执行。
  3. 保留模型的调用记录，按照供应商协议返回工具结果，并关联正确的调用标识。
  4. 再次调用模型，检查答案是否依据真实工具结果。
  5. 加一个“你好”之类无需工具的问题，验证直接回答路径。

这项任务怎么学

资料：官方工具调用流程与调用处理、结果回传。

方法：跟官方最小示例跑一次 → 换成自己的工具与问题 → 观察每步输入输出 → 关闭示例复述完整往返。

产出与验收：一条真实 API 的正常调用记录；能指出函数确实执行的证据，工具结果确实回传的位置，以及直接回答时如何结束。

建议时长：3h：官方最小协议示例 0.75h；独立接入请求、执行和回传 1.5h；直接回答与调用记录检查 0.75h。

任务三：理解 ReAct，手写 Agent Loop

5 小时
P0ReAct L2 · Loop L3

要解决的问题：一次结果可能不足以完成任务，程序需要允许模型根据反馈继续决定下一步。

ReAct 本周掌握“行动得到观察，观察影响下一步决策”的基本思想。Agent Loop 则把模型调用、工具执行、上下文更新与停止判断写进程序。当前 State 只需理解为本次任务正在使用的信息和执行状态；长期记忆暂不实现。

  1. 读 Hello-Agents 4.2.1 的流程，再读 4.2.3 的循环实现；用自己的话描述各部分职责。
  2. 先自己写一个同步循环骨架：调用模型、判断返回类型、执行工具、写回结果。
  3. 设置 max_steps，并在说明中明确“步数”采用什么计数口径，例如模型调用轮数。
  4. 为最终回答设置正常退出，为达到上限设置明确的未完成状态。
  5. 保留本次运行必要的调用记录；新任务开始时重新初始化，避免样例任务串状态。

教材与接口的分工：Hello-Agents 4.2 用文本格式演示 ReAct。本周用它理解控制流，工具请求与回传按所用模型的原生 Tool Calling 接口实现。调试重点是请求、参数、执行结果与终止原因。

这项任务怎么学

资料：Hello-Agents 4.1、4.2.1、4.2.3、4.2.4；当前模型官方接口文档。

方法：教材建立结构 → AI 解释数据流 → 你从骨架自己写 → 遇到问题先看变量和报错 → AI 给逐级提示 → 关闭答案补写循环。

产出与验收：可运行的最小 Agent；能讲清每次继续执行的依据，以及正常结束和步数耗尽的区别。

建议时长：5h：Hello-Agents 与控制流讲解 1.25h；手写循环和上下文更新 2.5h；步数上限与停止实验 0.75h；闭卷画图 0.5h。

任务四：处理失败与边界

3 小时
P0L2–L3

要解决的问题：成功示例之外，程序在输入无效、函数失败、模型持续调用工具时，仍能给出清楚的执行结果。

情况 要实现的行为
参数错误 捕获校验错误，不执行非法参数；形成明确的错误信息。
工具执行失败 捕获预期的执行异常，将失败信息交回模型，或按预先定义的规则终止。
达到最大步数 停止继续调用，输出“达到上限，任务未完成”的状态。
无需工具 正常返回答案，工具执行次数为 0。

这项任务怎么学

资料：Pydantic 校验错误、官方工具结果与错误处理、Hello-Agents 4.2.4。

方法：自己先写预期结果 → 故意制造失败 → 对照实际行为 → Debug → AI 检查遗漏。不要等待真实模型随机犯错，可以用固定模拟响应触发边界。

产出与验收：失败样例及验证脚本；每个场景都能说明失败位置、处理方式、是否继续，以及最后状态。

建议时长：3h：按需查错误处理 0.5h；构造异常响应与失败样例 1.5h；Debug 与状态核对 1h。

任务五：独立修改与闭卷验收

2 小时
P0 验收独立运行与解释

关闭完整答案，从循环骨架补完核心逻辑；再修改一个字段约束，或增加一个简单工具。修改后重新跑正常与异常验证。

这项任务怎么学

资料：自己的代码和下方验收表；卡住时先写下问题，再查对应页面。

方法：你独立操作 → ChatGPT 提问检查解释 → Codex 帮助检查代码与测试；学习成果不能只停在“看懂生成的代码”。

产出与验收：可解释的代码改动、运行说明、验证结果，以及一页数据流说明。

建议时长：2h：关闭答案补写循环 0.75h；修改字段约束或新增工具 0.5h；重跑验证并解释 0.5h；整理运行说明 0.25h。
