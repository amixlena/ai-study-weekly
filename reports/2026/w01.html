3. 每个任务的详细解读

1. Python 最低可用基线

P0L2

理解与用途：变量保存数据，条件控制分支，循环处理多条记录，函数把输入转成返回值；这些会直接出现在后续模型调用脚本中。

具体怎么做：在已有 baseline 中依次练字符串去空格、空值分支、列表遍历和函数返回。先预测输出再运行；把一个正常输入改为空字符串，观察是哪条分支生效。

学到这里即可：关闭示例后写出 2–3 个小函数，说明参数、返回值及一次报错原因。

2. Git 最小版本管理闭环

P0L2

理解与用途：工作区是当前文件，暂存区是本次准备记录的修改，commit 是保存的版本；它帮助你看清每次练习究竟改了什么。

具体怎么做：沿用已有仓库；只有尚未初始化时才 init。先 status，再 diff，确认文件后 add 指定路径并 commit，最后用 log 回看。修改同一函数再次走完流程。

学到这里即可：能独立记录一次修改，解释 diff 中增删行以及 add 与 commit 的区别。

3. 基础结果验证

P1L1–L2

理解与用途：验证是把预期结果写清楚，避免只因程序没有报错就判断正确。

具体怎么做：为同一函数写正常值和空值的最小断言；故意改错一个预期，观察失败，再修正。P0 尚未完成时不展开测试框架。

学到这里即可：能解释输入、预期输出与实际输出的差异；本周不要求完整 pytest 工程。

知识之间的关系

Python 语法→函数 / 数据结构→可运行练习→Git 记录变化→后续 AI 工程代码
