3. 本周 P0 / P1 / P2

P0 Python 基础可用性

变量、基本类型、条件、循环、函数、参数、返回值、import / module；目标是能读和改简单 AI 代码。

P0 Git 最小闭环

init、status、add、commit、diff、log；把学习产出纳入版本管理。

P1 基础验证

用最小测试或断言验证函数行为；理解“代码能跑”和“结果被验证”是两件事。

本周不做

OOP 深挖、Type Hint 系统课、复杂异常、算法题、Docker、FastAPI、Agent 框架。

4. 知识地图

Python 语法→函数 / 数据结构→可运行练习→Git 记录变化→后续 AI 工程代码

5. P0 学习方式映射

任务主导方式固定资料怎么用AI 怎么用必须动手何时算学完
Python 基线AI 主讲 + 实验主导Python 官方 Tutorial 只查本周语法与数据结构先解释陌生函数，再给小练习与逐级 Hint独立完成函数、循环、dict/list 操作能闭卷写出 2-3 个小函数并解释报错

6. 参考资料

  • Python 官方 Tutorial：只看控制流、函数、数据结构、模块相关页面。
  • Pro Git 简体中文版：重点第 2 章 Git Basics。
  • GitHub Docs · Git basics：用于核实远程仓库与常见工作流。
动态视频：这类基础内容文字和本地操作效率更高，本历史回顾页不为凑数额外塞视频；按 V2.1 规则优先官方文档 + 操作。

8. Definition of Done

  • ☐ 能独立写函数、参数和返回值
  • ☐ 能处理 list / dict 的遍历和基本嵌套
  • ☐ 至少一次故意制造并读懂 TypeError / ValueError 一类错误
  • ☐ 能解释 git status / diff / commit 的用途
  • ☐ 代码进入 Git 仓库，commit 信息可读
  • ☐ 关闭资料后能重写至少一个核心练习

9. 分工

你：真正写代码、运行、Debug、提交、闭卷重写。
ChatGPT：把 Python 基础按当前水平讲清、给 Hint 和边界测试。
Codex：只在你理解后做代码 Review 或小范围修改，不替代第一次独立实现。

W01 的重点不是“Python 学完”，而是建立最低可用基线。当前 V5.8 明确把 Type Hint、异常、OOP、uv、pytest 等放入后续 Just-in-Time 补齐，因此不应为了补全所有基础而阻塞 LLM / Agent 主线。
