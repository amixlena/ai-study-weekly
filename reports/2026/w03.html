3. 本周 P0 / P1 / P2

P0 Python / Git 综合验收

独立完成一个小脚本或 Notebook：读取结构化输入 → 函数处理 → 输出结果 → Git 提交。

P0 Debug 与解释能力

故意制造至少一个错误，读 traceback，定位并修复；能解释自己写的函数和数据流。

P1 JIT 欠账登记

把 Type Hint、异常、OOP、uv、pytest 等列为触发式待办，明确什么时候才需要补。

本周不做

不系统学完整 Python 工程课；不刷算法；不提前学 FastAPI、Docker、LangGraph。

4. 知识地图与阶段门

Python 基础+Git 基础→可运行小闭环→JIT 清单→W04 LLM / API

这周真正解决的是“何时停止补基础”。只要能独立运行、修改、Debug 和 commit，就不再等待所有工程知识学完。

5. P0 学习方式映射

任务主导方式固定资料怎么用AI 怎么用必须动手何时算学完
综合小闭环实验 / 项目主导只查 Python / Git 忘记的点给验收题、Hint、Review从空文件或骨架独立写出正常路径能跑，能解释数据流
Debug实验主导Python Errors & Exceptions 作为查错参考先提示看 traceback，不直接给答案故意制造 TypeError / KeyError 等并修复能指出错误类型、位置、原因和修复方式
JIT 清单AI 主讲uv / typing 等官方页只做未来入口说明每项“什么时候会阻塞”写成待办，不要求全部实践知道何时补，而不是现在全部学

6. 参考资料

  • Python Tutorial · Errors and Exceptions：本周用于 traceback 与异常直觉，不要求完整异常系统课。
  • Python typing 官方文档：仅作为后续 Type Hint 的入口。
  • uv Getting Started：只建立“以后项目依赖管理会用到”的位置感。
  • Pro Git · Git Basics Summary：用来做阶段收尾自检。
动态视频：W03 的目标是收尾和验收，不是继续输入新课；因此不增加额外视频。
