2. 本周 P0 / P1 / P2

P0 Python 数据结构

list、dict、set、tuple；遍历、查找、排序、推导式、嵌套结构。

P0 函数与模块继续使用

把数据处理拆成函数；理解 import/module，避免所有逻辑堆在一个单元。

P0 Git 日常工作流

status → diff → add → commit → log；开始理解 remote / push / pull。

本周不做

复杂 OOP、Generic/Protocol、算法刷题、完整 pytest 系统课、Docker / FastAPI。

3. 知识地图

原始数据→list / dict→函数处理→结果验证→Git commit

AI 应用里非常常见的 messages=[{"role":"user","content":"..."}] 本质就是嵌套数据结构；这一周学的是后面读 API / Agent 代码时每天都会碰到的能力。

7. 可验证产出

  • 一个处理嵌套 list/dict 的小脚本或 Notebook。
  • 至少包含一次过滤、统计、排序和结构转换。
  • 代码拆为多个函数，而不是单块堆叠。
  • Git 中有可读的多个 commit，可以用 diff/log 解释每轮变化。

8. 闭卷验收

  • ☐ list、tuple、set、dict 的核心差异能讲清
  • ☐ 能对嵌套 dict/list 做遍历和修改
  • ☐ 能写 list/dict comprehension
  • ☐ 能把逻辑拆函数并 import
  • ☐ 能解释 staging area 的作用
  • ☐ 能使用 diff/log 找到一次修改
