9. 推荐执行顺序

  1. 先建立总图：AI 主讲 30–45 分钟，把生成链串起来。
  2. Token / Tokenizer 实验：立即做三个输入对比。
  3. 原课程选段：Attention / Transformer 只看本周深度需要的部分。
  4. API 最小调用：跑通 messages / response，记录 usage。
  5. 参数对照：一次只改一个变量。
  6. Streaming / Error：做真实运行和故意失败。
