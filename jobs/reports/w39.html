03 / JD 与个人匹配

应用 / Agent / 后端

共性是 Python、模型 API、工具调用、RAG、REST 接口、部署与故障处理。部分后端平台岗偏 Go/K8s/分布式，须看职责实质。

已有基础：统计与 SQL、业务数据分析。需补证据：独立开发的 Agent API、参数校验、异常路径、测试与部署。

技术型评测 / 数据 Pipeline

核心是 Golden Set、指标、任务运行、版本、质量检查和结果复现。训练研究岗与纯标注不混入工程岗位。

可迁移能力：指标、实验与问题归因。需补证据：自动评测代码、固定数据集、运行日志与可比较报告。

技术要求层级：必须建立 Python / API / Git / 测试 / 工具调用；常见加分是 Docker、RAG、数据库、Tracing、评测；分布式调度、K8s、模型训练和大规模数据平台是部分较高级岗位要求，不因此改成全栈系统课程。

PDE/FDE：本期没有足以核验职责与开发占比的直接岗位页，因此不把售前、纯实施、低代码方案岗计入。

本期行动：先做一个可演示的 Agent API：正常调用、参数错误、工具失败、最大步数、日志与测试均有证据；投递时按公司、年限和职责再核。
